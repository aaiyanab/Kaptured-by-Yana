## 🚀 Deploy to Vercel (Recommended — Free, Takes 2 min)

1. **Create a free account** at [vercel.com](https://vercel.com)
2. **Push this folder to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   gh repo create kapturedbyyana --public --push
   ```
   *(Install GitHub CLI at cli.github.com if you don't have it)*
3. **In Vercel:** Click "Add New Project" → Import from GitHub → Select your repo → Deploy
4. Your site is live at `https://kapturedbyyana.vercel.app` (or connect your own domain)

---

## 🐙 Deploy to GitHub Pages (Also Free)

1. Push this folder to a GitHub repo named `kapturedbyyana`
2. Go to **Settings → Pages**
3. Set Source: `Deploy from branch` → `main` → `/ (root)`
4. Your site is live at `https://yourusername.github.io/kapturedbyyana`

## ✏️ Customizing

- **Add your email:** Search `hello@kapturedbyyana.com` in `index.html` and replace
- **Add photos:** Drop images in an `images/` folder, update `src` attributes
- **Change colors:** Edit CSS variables at the top of `css/style.css`
- **Add sections:** Copy an `ecard` block in `index.html` and update content
